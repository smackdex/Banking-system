
# Python Banking System

A terminal-based banking application developed with Python to
simulate basic banking operations through an interactive menu.

The application demonstrates how Python functions, conditional
statements, input validation, and JSON file handling can be used
to organize a simple banking workflow.

Users can register, log in, perform basic account operations,
and review transaction information.

This project was developed as part of my practical journey in
Python programming.

## Features

### User Management

- User registration.
- Input validation during registration.
- Password confirmation.
- Login 

### Banking Operations

- Deposit money into an account.
- Withdraw money from an account.
- Transfer money between accounts.
- Check account balance.
- View transaction history.

### Data Persistence

- Store banking data in a JSON file.
- Retrieve previously stored data for subsequent sessions.

## How It Works

The application presents users with a terminal-based menu
through which they can access available banking operations.

Users can register and log in before accessing the relevant
account functionality.

The application provides operations for deposits, withdrawals,
transfers, balance enquiries, and transaction history.

The main application file manages the menu and program flow,
while the banking functionality is organized into a separate
Python module.

JSON file handling provides persistence for application data,
allowing stored information to be retrieved in later sessions.

banking information.

The data file is expected to be available at the location
specified by the application.

Do not upload real banking information, personal account details,
or other sensitive data to a public repository.
